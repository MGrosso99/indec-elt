System design · v1 warehouse

Pipeline ELT de series del INDEC

Extracción con Airbyte, warehouse en Postgres, modelado con dbt, orquestación con Airflow, BI en Metabase. Observabilidad de datos con Elementary y de infraestructura con Prometheus + Grafana. CI/CD en GitHub Actions.

Corrida diaria

  1. Sync de AirbyteAirflow dispara la conexión. Airbyte llama a la API con el token y hace upsert en raw por (serie_id, fecha).
  2. dbt buildCosmos corre staging, intermediate, marts y snapshots con sus tests. Cada modelo es una task, así un fallo se ve puntual.
  3. Elementaryedr monitor revisa tests, freshness, volumen y cambios de schema, y alerta a #alertas-datos.
  4. MetabaseLos dashboards leen los marts actualizados con un usuario de solo lectura.
  5. En paraleloPrometheus junta métricas de Airflow, Postgres y contenedores; Grafana alerta a #alertas-infra.
